# Rima & Ramroma WordPress Theme

This theme implements the Figma **Rima Page** with Bootstrap 5, Font Awesome 6, responsive layouts, Polylang compatibility, reusable shortcodes, and a dashboard control panel.

## Setup

1. Place this directory in `wp-content/themes/` and activate **Rima & Ramroma**.
2. Use the automatically rendered front page, or assign the **Rima Page** template to any WordPress page.
3. Open **Appearance → Rima Theme Controls** to edit content, images, links, icons, colors, type sizes, visibility, and section order.
4. With Polylang active, translate registered theme strings from **Languages → Translations**. The header language menu is hidden unless two or more languages exist.

## Shortcodes

- `[rema_rima_page]` — the complete ordered Rima page
- `[rema_hero]`
- `[rema_intro]`
- `[rema_brands]`
- `[rema_divider]`
- `[rema_vision]`
- `[rema_mission]`
- `[rema_values]`
- `[rema_lifestyle_family]`
- `[rema_lifestyle_back]`

The control panel includes an embedded desktop/tablet/mobile preview and a **Restore Figma defaults** action.
